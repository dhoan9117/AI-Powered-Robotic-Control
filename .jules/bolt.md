## 2024-06-09 - Redundant Serial Writes in Control Loop
**Learning:** In `code/dieukhien_servo.py`, the application writes to the Arduino (`arduino.write(cmd.encode())`) in every iteration of the `cap.isOpened()` loop, regardless of whether the calculated servo angles (`current_base`, `current_gripper`, `current_arm`, `current_wrist`) have actually changed. Serial communication is a slow, blocking I/O operation. Writing identical commands repeatedly clogs the serial buffer, wastes CPU cycles, and introduces unnecessary latency into the real-time video processing pipeline. The `code/test.py` file correctly implements a "send only on change" pattern (`if current_data != last_data`), but `dieukhien_servo.py` does not.
**Action:** Implement the delta-based write optimization from `test.py` into `dieukhien_servo.py`. Introduce a `last_cmd` tracking variable and only call `arduino.write()` if `cmd != last_cmd`.
