## 2025-02-12 - Delta-Based Hardware Writes Optimization
**Learning:** In applications sending frequent, identical commands to external hardware (like PySerial communicating with Arduino inside a tight video processing loop), unconditional sequential writes can cause substantial overhead, driver contention, and potential hardware buffer overflows. The Serial I/O overhead blocks the CPU while waiting for the OS buffer to clear.
**Action:** Implement delta-based state tracking. Before dispatching any command over Serial, compare the newly computed string (e.g., `cmd = f"{x},{y}\n"`) with the previously sent command (`last_cmd`). Only trigger `arduino.write()` and update `last_cmd = cmd` when there is an actual state change, significantly reducing loop execution time and I/O bloat.
